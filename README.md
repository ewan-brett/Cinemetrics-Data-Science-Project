# MA22019 Coursework 1 Repository

This private repository stores your Coursework 1 submission and your released
feedback.

## What Is In This Repository

The minimum contents of this repository are:

- `coursework_01.qmd` is the main coursework file.
- `coursework_01.Rproj` is the RStudio project file.
- `data/` contains the coursework datasets.
- `*_feedback.md` is your released feedback file.

Your repository may also contain other files from your own work on the
coursework.

## How To Read Your Feedback

1. Open the feedback file in the repository root. Its name ends with
   `_feedback.md`.
2. Read the `Overall` section first. This shows the released total for the
   coursework.
3. Then read each task section in order. The feedback explains what was done
   well, what was partly correct, what lost marks, and what would have improved
   the answer further.
4. If your feedback begins with an important note at the top, read that before
   the task-by-task comments because it explains a submission-format or
   word-limit issue that affected release handling.

## How To Access The Updated Files

If you work in RStudio with Git:

1. Open your coursework project in RStudio.
2. Click the `Pull` button in the Git pane to download the released feedback.
3. Open the feedback file from the Files pane or on GitHub Enterprise.

If you are not using Git locally:

1. Open your private coursework repository on GitHub Enterprise in your
   browser.
2. Open the feedback file in the repository root, or download that file on its
   own if you prefer.
3. You can also download the whole repository if you want to keep a local copy
   of the released record.

## Important Notes

- The released total is the total shown in your feedback file. If an overall
  deduction has been applied, that is already reflected in the released total
  shown there and explained in the top note of the feedback file where
  relevant.
- If you want this repository to remain your released coursework record, do not
  push further changes to it.
- If you have a question about the feedback, contact your lecturer at
  kai21@bath.ac.uk.
